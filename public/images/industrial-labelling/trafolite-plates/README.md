# Trafolite Labelling — Product Image Directory

Upload product photographs for the **Trafolite Labelling** category here.

## Image Guidelines
- **Product Type**: Trafolite-style engraved labels, multi-layer phenolic / acrylic tags, electrical control panel labels, warning and instruction tags.
- **Recommended Formats**: PNG (transparent background preferred), WebP, or high-resolution JPG.
- **Background**: For best visual presentation on the website, transparent PNG images with genuine alpha transparency are strongly recommended.
- **Filenames**: Use clear, lowercase, kebab-case filenames (e.g. `trafolite-panel-tag-01.png`, `engraved-switch-label-02.png`).
- **Original Uploads**: Upload your original untouched camera photos to `public/images/industrial-labelling-originals/trafolite-labelling/`, then run the background removal process to export the transparent PNG into this directory.

The website automatically displays images placed in this folder on the Industrial Labelling overview card and the dedicated Trafolite Labelling gallery page.
