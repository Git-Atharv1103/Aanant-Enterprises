# Panel Door Locks — Product Image Directory

Upload product photographs for the **Panel Door Locks** category here.

## Image Guidelines
- **Product Type**: Industrial electrical enclosure door locks, quarter-turn cam locks, handle locks, panel latches, and related enclosure hardware.
- **Recommended Formats**: PNG (transparent background preferred), WebP, or high-resolution JPG.
- **Background**: For best visual presentation on the website, transparent PNG images with genuine alpha transparency are strongly recommended.
- **Filenames**: Use clear, lowercase, kebab-case filenames (e.g. `panel-door-lock-01.png`, `quarter-turn-cam-lock-02.png`).
- **Original Uploads**: Upload your original untouched camera photos to `public/images/industrial-labelling-originals/panel-door-locks/`, then run the background removal process to export the transparent PNG into this directory.

The website automatically displays images placed in this folder on the Industrial Labelling overview card and the dedicated Panel Door Locks gallery page.
