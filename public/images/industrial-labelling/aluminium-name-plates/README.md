# Aluminium Name Plates — Product Image Directory

Upload product photographs for the **Aluminium Name Plates** category here.

## Image Guidelines
- **Product Type**: Aluminium nameplates, anodized aluminium serial plates, machine identification nameplates, and branded equipment badges.
- **Recommended Formats**: PNG (transparent background preferred), WebP, or high-resolution JPG.
- **Background**: For best visual presentation on the website, transparent PNG images with genuine alpha transparency are strongly recommended.
- **Filenames**: Use clear, lowercase, kebab-case filenames (e.g. `aluminium-nameplate-01.png`, `anodized-equipment-plate-02.png`).
- **Original Uploads**: Upload your original untouched camera photos to `public/images/industrial-labelling-originals/aluminium-name-plates/`, then run the background removal process to export the transparent PNG into this directory.

The website automatically displays images placed in this folder on the Industrial Labelling overview card and the dedicated Aluminium Name Plates gallery page.
