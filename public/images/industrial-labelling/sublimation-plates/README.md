# Sublimation Plates — Product Image Directory

Upload product photographs for the **Sublimation Plates** category here.

## Image Guidelines
- **Product Type**: Heat-transferred / sublimation printed metal plates, multi-color identification signs, customized display plaques, and full-color branded plates.
- **Recommended Formats**: PNG (transparent background preferred), WebP, or high-resolution JPG.
- **Background**: For best visual presentation on the website, transparent PNG images with genuine alpha transparency are strongly recommended.
- **Filenames**: Use clear, lowercase, kebab-case filenames (e.g. `sublimation-plate-01.png`, `color-printed-plaque-02.png`).
- **Original Uploads**: Upload your original untouched camera photos to `public/images/industrial-labelling-originals/sublimation-plates/`, then run the background removal process to export the transparent PNG into this directory.

The website automatically displays images placed in this folder on the Industrial Labelling overview card and the dedicated Sublimation Plates gallery page.
